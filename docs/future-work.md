# 今後の課題

設計書の完了条件「重要なセーブをバックアップできる方法を用意する、または今後の課題として明示する」について、② の時点では作らず、ここに課題として残す。

## ゲーム内セーブのバックアップ（エクスポート／インポート）

- いまのゲーム内セーブ（セーブ RAM・RTC）は端末内の localStorage（キー `sram:<ROM の ID>` / `rtc:<ROM の ID>`）にしかない。
- `navigator.storage.persist()` を起動時に呼んでいるが、許可されても、ユーザーによるサイトデータの削除・ホーム画面アプリの削除・端末の故障・機種変更では失われる。iOS では Safari とホーム画面アプリで保存領域が別になることもある。
- 必要になったら、ROM ごとのセーブ RAM（と RTC）をファイルに書き出す・読み込む機能を足す。書き出し形式は本家 `frontends/web` のバックアップ機能（今回は移していない）を参考にする。
- それまでの代わり: セーブステート（`.rbs`）のダウンロードは使える。ただし本家の版を上げると古いセーブステートは読めなくなることがある（`docs/upstream-notes.md`）。

## そのほか
